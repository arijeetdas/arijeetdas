## 📡 DropNet

<div align="center">

### **Local file transfer without depending on the internet.**

<a href="https://dropnet.arijeet.in">
<img src="https://img.shields.io/badge/🌐%20LIVE%20WEBSITE-00C6FF?style=for-the-badge" alt="DropNet website"/>
</a>

<a href="https://git.dropnet.arijeet.in">
<img src="https://img.shields.io/badge/💻%20SOURCE-161B22?style=for-the-badge&logo=github&logoColor=white" alt="DropNet source"/>
</a>

</div>

DropNet is my main project — a **Flutter-based cross-platform local file-transfer application** designed for direct device-to-device communication over a local network.

### 📱 Platform targets

<div align="center">

`ANDROID`  •  `WINDOWS`  •  `LINUX`  •  `MACOS`  •  `IOS`

</div>

### 🔥 What I've explored while building it

| Technology / Concept | What it enabled                |
| -------------------- | ------------------------------ |
| 🔌 TCP Sockets       | Direct device communication    |
| 🌐 Local Networking  | Internet-independent transfers |
| 📡 Device Discovery  | Finding peers on the network   |
| 🖥️ Local Servers    | Hosting transfer endpoints     |
| 🔐 Private Profiles  | Controlled network discovery   |
| 🌍 Web Portal        | Browser-based receiving        |
| 🐧 Linux Packaging   | AppImage / `.deb` distribution |
| 🪟 Windows Packaging | Native installer distribution  |
| 🍎 macOS             | Desktop application builds     |
| 📦 Android           | Multiple APK architectures     |

### 🌍 The Web Portal

One of the features I particularly like is **app-free receiving**.

A device can open a browser and receive files without installing DropNet.

```text
                    LOCAL NETWORK
                         │
              ┌──────────┴──────────┐
              │                     │
              ▼                     ▼
        ┌───────────┐         ┌───────────┐
        │  DropNet  │         │  DropNet  │
        │  Device A │────────▶│  Device B │
        └───────────┘         └───────────┘
              │
              │
              ▼
        ┌─────────────┐
        │   Browser   │
        │  Web Portal │
        └─────────────┘
```
